# Оно тебе надо

Учебный проект Яндекс Практикума: страница аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/Rusel998/ono-tebe-nado-ad

## О проекте

Страница содержит шапку с навигацией, обложку, три карточки лотов, раздел об аукционе и подвал. Вёрстка выполнена на HTML и CSS с использованием Grid и Flexbox. Шрифты и изображения хранятся в проекте.

Макет рассчитан на экраны шириной от 1100 пикселей. Мобильная версия в задании не предусмотрена.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не требуются.

## Структура

- `index.html` — разметка страницы.
- `styles/` — глобальные стили и оформление секций.
- `fonts/` — локальные шрифты Raleway и их подключение.
- `images/` — изображения лотов, обложка, логотипы и социальные иконки.

Автотесты запускаются в GitHub Actions после отправки изменений.
